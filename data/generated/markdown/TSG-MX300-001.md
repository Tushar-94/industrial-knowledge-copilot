## 2. Purpose

## 3. Alarm Response Principles

Alarm codes identify abnormal machine conditions. Operators should follow the stated operator action and escalate faults requiring maintenance intervention.

Critical safety alarms must not be bypassed or repeatedly reset without the underlying cause being corrected.

## 4. Alarm Reference

## HX-417 — Hydraulic Pressure Below Operating Threshold

**Severity:** High

### Description

Hydraulic pressure remained below the required operating range during the production cycle.

### Trigger Condition

Measured pressure below model operating threshold

### Possible Causes

- Low hydraulic fluid level
- Return filter restriction
- Hydraulic pump degradation
- Internal hydraulic leakage
- Pressure relief valve misadjustment
- Pressure sensor error

### Diagnostic Checks

1. Verify reservoir fluid level
2. Inspect for visible hydraulic leaks
3. Check return filter differential pressure
4. Measure hydraulic pump discharge pressure
5. Compare pressure sensor reading with service gauge

### Operator Action

Stop the production cycle and escalate the alarm to authorized maintenance personnel.

### Maintenance Action

Diagnose the hydraulic-pressure loss before returning the machine to production.

### Related Procedures

- **SOP-MNT-001** — Hydraulic System Inspection
- **SOP-OPS-002** — Controlled Shutdown and Alarm Escalation
