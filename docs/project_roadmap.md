
# Project Roadmap

## Project

Industrial Knowledge Copilot

## Objective

Build a realistic, evaluation-driven RAG and agentic AI system for technical operations knowledge using independently created synthetic industrial documents and structured operational data.

## Core principles

1. Understand each component before adopting abstractions.

2. Add technology only when it solves a demonstrated problem.

3. Evaluate retrieval and generation separately.

4. Use deterministic software for deterministic tasks.

5. Preserve source traceability.

6. Never publish employer code, confidential information, or proprietary data.

7. Build incrementally and maintain a deployable repository.
